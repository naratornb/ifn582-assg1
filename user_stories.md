User stories / Acceptance Criteria

### 1. Landing Page

User Story 1: 

**Title: Allow Users to Search for Specific Products**

**Story:** As a user, I want to search for desired products by name or keywords so that I can quickly find specific items.

**Acceptance Criteria:**

- The search box must be prominently placed on the navigation bar for easy discovery.
- The search box must accept product names or keywords entered by the user.
- The search box must include a submit button to trigger the search.
- The system must display relevant results immediately after the user submits a search query.

**User Story 2:**

**Title:** Filter Grocery Items by Categories
**Story:** As a user, I want to filter items by categories (e.g., food, shops, restaurants) so that I can narrow down my product search.

Acceptance Criteria:

- A filter button with a recognizable icon must be clearly visible.
- Clicking the filter button must display a list of grocery item categories.
- Selecting a category must update the product list to show only items in that category.

**User Story 3:**

**Title: View Product List and Add to Cart**

***Story:** As a user, I want to see a list of products so that I can see variety of products selling on this website and add the items to my cart at instances.*

Acceptance Criteria:

- A product list must have item’s images, name and price listed to visualize products to the user
- A product list must have an “Add to Cart” button to allow user shopping from landing page
- User must be able to add desired products from product list and update the cart

### 2. Item Details Page

User Story 4:

**Title:** View product details

**Story:** *As a customer, I want to view detailed information about a grocery item so that I can make an informed purchase decision.*

**Acceptance Criteria:**

- The item details page must include images, a product name, a product description, and pricing.
- The pricing of the product must be displayed in Australian Dollars (AUD)

User Story 5:

**Title:** Add Item to Cart from Details Page

**Story:** As a customer, I want to add an item to my cart directly from the details page after reviewing its information.

**Acceptance Criteria:**

- A clear “Add to Cart” button must be prominently displayed on the details page.
- Clicking the button must add the item to the cart.

---

### 3. Delivery Request Page

**User Story 6:**

Title: **:** View Cart Summary in delivery request page

Story: As a user, I want to review a summary of selected items so that I can see all my added items

**Acceptance Criteria:**

- The delivery request page must list all items added by the user.
- Each item in the delivery request page must displays name, quantity, and price of that specific items

**User Story 7:**

Title: Adjust Cart Items Before Checkout

Story: As a user, I want to adjust quantities or remove items from my cart to finalize my order

**Acceptance Criteria:**

- Each item must have a "Remove" button to delete it from the cart.
- A "Proceed to Checkout" button must be prominently displayed once adjustments are made.

---

### 5. Checkout Page

**User Story 8:**

**Title: Review Pricing Summary**

**Story:** *As a user, I want to see price of each unit and total price so that I can confirm affordablility.*

**Acceptance Criteria:**

- The checkout page must display a clear breakdown of the orders, including items, quantities, pricing, delivery details, and applicable taxes/fees.
- The price must be shown in Australian Dollars (AUD)

**User Story 9:**

**Title: Specify Recipient Details**

**Story:**  As a user, I want to enter recipient details so that I can ensure delivery to the correct address.

**Acceptance Criteria:**

- The checkout page must have a form to input details of the recipient, including name, contact phone number and delivery address
- The system must validate that phone numbers are Australian (e.g., +61 format)
- The system must validate that delivery addresses are within Australia.

**User Story 10:**

**Title: Select Delivery Method**

**Story:** *As a user, I want to choose a delivery method so that I can have my desirable estimation fees and delivery times* 

**Acceptance Criteria:**

- The checkout page must display available delivery options (e.g., green, express).
- Each option must show its delivery method name, delivery fee and estimated delivery time
